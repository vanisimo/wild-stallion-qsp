## Согласованный канон (дизайн, не весь в коде)

### Танцы / Аманда (ГГ)

| Условие | Поведение |
|---------|-----------|
| `AmandaHomeStage < 1` | Только танец / поболтать на площади; обида → блок вечера; **нет** подворотни, нет ухода домой с танцев |

| Легаре | **Вариант α** — уводит **независимо** от домашней лестницы ГГ |
| Девственность ГГ | vaginal только **дома** (`amanda_home_chain`); Легаре может в подворотне |

### Спонсорство

- **Только** выбор при смене дня чт→пт (Сандра): спонсировать / нет.
- **Нет** кнопки угощения на площади; если спонсировали — **пассивный ларёк**, NPC сами пьют/едят.
- Стоимость: 10/5/8, без денег; в статистике — **отдельный блок**; прибыль четверга **не** пересчитывается.
- Не спонсировали = обычная площадь, **без штрафа**.

### Act 1 — ядро сюжета (обсуждение)

**Центральный конфликт:**

> Стефан хочет **дворянство**. **Мэр** — барьер/таможня. **Деньги** — топливо.  
> Раскол: **узда** (честно, долго, семья) vs **свобода** (быстрее деньги + грязь → мэр «ускоряет»).

**Контракт игрока — смесь А + В:**

- **А:** NTR / грязь в основном **вина игрока** (медлил, отпустил, спонсировал, policy 3…).
- **В:** две **равноценные** финальные идентичности — чистая семья vs открытая коррупция (не fail state).

**Стратегия «отпустить возжи» — вариант В (оба фронта):**

| Фронт | Узда | Свобода |
|-------|------|---------|
| **Зал** | harassment protect + policy 1, найм | ignore / watch + policy 3 |
| **Площадь** | без спонсорства, вмешаться с Легаре, дом | спонсорство, танец без дома, дать уйти |

Мэр читает **сумму** (или **разрыв** — «двуличный трактирщик»).

**Треугольник:** ДВОРЯНСТВО ↔ ДЕНЬГИ ↔ СЕМЬЯ.

Связь с `docs/design-mayor-seal-corruption-arc.md`: путь 1 честный (долго), путь 2 ускорение при низкой репутации + коррупция; второй приём — желание, не насилие.

  - зал: прилично / решать самой / удерживать ради чаевых;
  - кухня: звать Стефана / решать самой / любой ценой.
  - Policy **3** ≈ `HallHarassmentResultProfit` (+money, scandal++).
