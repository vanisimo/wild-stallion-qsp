# Руководство по настройке коннекторов и MCP на другой машине

Данное руководство описывает, как развернуть и подключить все необходимые коннекторы (MCP-серверы, проверку кода, память и генератор изображений) на второй рабочей машине.

---

## 1. Базовые системные требования

На второй машине должны быть установлены:
1. **Node.js** (версия 20+ LTS или новее) — нужен для запуска MCP-пакетов через `npx`.
   * Проверка в терминале: `node -v` и `npx -v`.
2. **Git** — для работы с кодом и версионированием.
   * Проверка: `git --version`.
3. **Python 3.10+** — для вспомогательных скриптов аудита и проверки.
   * Проверка: `python --version`.
4. **qsp-cli** (глобальный компилятор QSP):
   * Установка при необходимости: `npm install -g @qsp/cli`
   * Проверка: `qsp-cli --version`.

---

## 2. Настройка MCP-серверов в Antigravity

Файл глобальной конфигурации MCP в Antigravity находится по пути:
* **Windows:** `C:\Users\<Ваш_Пользователь>\.gemini\config\mcp_config.json`
* *(Если папки `.gemini\config` нет, создайте её вручную).*

### Содержимое файла `mcp_config.json`:

```json
{
  "mcpServers": {
    "memory": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-memory"]
    },
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "E:/TraKtir"
      ]
    },
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_PERSONAL_ACCESS_TOKEN": "ВАШ_GITHUB_ТОКЕН_ЗДЕСЬ"
      }
    }
  }
}
```

> ⚠️ **Важно:** 
> 1. В блоке `"filesystem"` укажите **фактический путь** к папке проекта на этой машине (например, `"D:/TraKtir"` или `"C:/Projects/TraKtir"`). Используйте прямые слэши `/`.
> 2. В блоке `"github"` укажите ваш персональный токен доступа GitHub с правами `repo`.

## 3. Синхронизация навыков проекта (QSP Workflow Skill)

В репозитории проекта уже настроена папка `.agents/skills/qsp-workflow/`.
После того как вы склонируете репозиторий или сделаете `git pull`:
* Antigravity автоматически обнаружит навык сборки и валидации.
* Ассистенту будут доступны команды автоматической проверки синтаксиса (`scripts/check.ps1`) и сборки (`scripts/build.ps1`).

---

## 4. Подключение генератора изображений (с GPU-машины)

Если генератор картинок (ComfyUI / Stable Diffusion / Flux) запущен на машине с производительной видеокартой, мы подключаем его по локальной сети:

### Вариант А: Запуск ComfyUI с открытым сетевым портом
1. На GPU-машине запустите ComfyUI с параметром `--listen 0.0.0.0` (по умолчанию порт `8188`).
2. Узнайте локальный IP-адрес GPU-машины (в командной строке: `ipconfig`, например `192.168.1.50`).

### Вариант Б: Подключение через MCP Image Server (SSE)
В `mcp_config.json` на рабочей машине добавляется секция:
```json
    "image-generator": {
      "serverUrl": "http://192.168.1.50:8000/sse"
    }
```
*(Либо прямой вызов API генерации через скрипт `scripts/generate_art.py`, принимающий промпт и сохраняющий файл в `images/` проекта).*

---

## 5. Проверка работы после настройки

1. Перезапустите Antigravity или начните новую сессию.
2. В интерфейсе нажмите меню **«...» (Additional Options) ➔ MCP Servers**:
   * `memory` — должен быть в статусе **Connected**.
   * `filesystem` — должен быть в статусе **Connected**.
   * `github` — должен быть в статусе **Connected**.
3. Для проверки компиляции проекта выполните в терминале:
   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts/build.ps1 -Profile dev
   ```
