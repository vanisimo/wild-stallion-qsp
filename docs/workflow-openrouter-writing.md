# Настройка OpenRouter для написания сцен, диалогов и квестов

Руководство объединяет все рабочие способы подключения моделей **OpenRouter** к проекту **«Дикий Жеребец»** (`Wild Stallion QSP`) — от чат-программ с интерфейсом до генератора из терминала и Aider.

Связанные документы:
- [docs/workflow-sillytavern-generation.md](workflow-sillytavern-generation.md) — подробный гайд по SillyTavern и сэмплерам для 18+ сцен.
- [docs/design-stefan-voice.md](design-stefan-voice.md) и [docs/design-npc-voices.md](design-npc-voices.md) — канон характеров и речи.
- `AGENTS.md` и `GEMINI.md` — правила мира, религии (Ильматер, святой круг, порошок «Таро»), валюты (спринтрии) и стилистики.

---

## 1. Какие «чат-программы» подключаются к OpenRouter

Если нужен привычный оконный/браузерный чат, куда вставляется ключ OpenRouter и выбирается модель:

1. **SillyTavern** — лучший выбор для **18+ сцен и отыгрыша персонажей**.
   - Поддерживает карточки персонажей (Стефан, Аманда, Мелисса, Сандра), `Author's Note`, сэмплеры (`Min-P`, `Temperature`, `Repetition Penalty`) и выбор OpenRouter как бэкенда (`API Connections -> Chat Completion -> OpenRouter`).
   - Подробная настройка уже описана в [docs/workflow-sillytavern-generation.md](workflow-sillytavern-generation.md).
2. **Cherry Studio** (десктоп для Windows) — универсальная чат-программа для **обычных диалогов, квестов и работы с лором**.
   - В `Settings -> Model Providers -> OpenRouter` вставляется ключ `sk-or-v1-...`, после чего в чате можно переключать любые модели в один клик.
   - Умеет создавать отдельных «Ассистентов» (например, *Сценарист диалогов* и *Редактор 18+*) и прикреплять файлы `AGENTS.md`, `GEMINI.md`, `docs/design-npc-voices.md` в локальную **Knowledge Base**, чтобы модель помнила лор.
3. **Chatbox** или **Open WebUI** — похожие чат-клиенты (Open WebUI удобен в Docker, Chatbox — лёгкое десктоп-приложение), где OpenRouter подключается через OpenAI-совместимый API (`https://openrouter.ai/api/v1`).

## 3. Вариант 1 — Скрипт генерации в проекте (`scripts/generate_text.py`)

Скрипт уже встроен в проект, не требует установки сторонних библиотек и автоматически подставляет:
- канон мира (`ты` к Стефану, Ильматер, святой круг, Таро, спринтрии, без запахов окружения, не более 1 прилагательного);
- профили персонажей (`--char amanda melissa`);
- уровень семейной коррупции (`--corruption 0..5`);
- форматирование сразу в QSP-строки `*pl '...'` (`--qsp`).

### Настройка ключа
1. Скопируйте `.env.example` в `.env` в корне репозитория (`<корень репозитория>\.env`).
2. Впишите свой ключ `OPENROUTER_API_KEY=sk-or-v1-...` (файл `.env` добавлен в `.gitignore`).

### Примеры запуска (PowerShell)
```powershell
# Посмотреть пресеты моделей
python scripts/generate_text.py --list-models

# Посмотреть актуальные модели и цены прямо с OpenRouter
python scripts/generate_text.py --live-models --filter deepseek

# Сгенерировать 18+ сцену и сразу получить строки *pl '...'
python scripts/generate_text.py --mode nsfw --char stefan amanda --corruption 3 --qsp --prompt "За сараем вечером: Аманда дразнит Стефана, он неловко отвечает и касается её талии."

# Сгенерировать живой диалог по готовому файлу брифа из promt/
python scripts/generate_text.py --mode dialog --char stefan melissa --brief-file promt/melissa_all_scenes_concept.txt --qsp --out scratch/melissa_draft.txt

# Попробовать другую модель на лету
python scripts/generate_text.py --mode nsfw --model sao10k/l3.1-euryale-70b --char amanda --qsp --prompt "..."
```

## 4. Вариант 2 — Aider в терминале с OpenRouter

`aider` уже установлен в системе. Для запуска с OpenRouter задайте ключ в сессии PowerShell:

```powershell
$env:OPENROUTER_API_KEY = "sk-or-v1-..."
aider --model openrouter/deepseek/deepseek-v4-pro modules/events/amanda/...
```

Или для 18+ прозы:
```powershell
aider --model openrouter/deepseek/deepseek-v3.1-terminus
```

Посмотреть список моделей OpenRouter, известных Aider:
```powershell
aider --list-models openrouter/
```

## 5. Вариант 3 — Готовый System Prompt для Cherry Studio / Chatbox / SillyTavern

Скопируйте этот блок в **System Prompt** вашей чат-программы (для диалогов и 18+ сцен):

```text
Ты — сценарист текстовой RPG/новеллы «Дикий Жеребец» (Wild Stallion QSP).
Пиши на живом, ёмком и динамичном русском языке.

КАНОН МИРА И СТИЛЯ:
1. Обращение к ГГ (Стефану) в описании действий и мыслей — строго на «ты» («Ты подходишь», «Ты видишь»). Никакого «Вы/вы».
2. Религия: верховное божество — Ильматер. Никаких «боже», «ради бога», «Господи» — только «Ильматер», «ради Ильматера», «видит Ильматер». Вместо креста — «знак Круга», «осенить себя святым кругом».
3. Чистота: вместо бритв используют серый храмовый порошок «Таро» (женщины убирают волосы полностью, мужчины оставляют полоску/треугольник над удом).
4. Валюта: только «спринтрии» (не мараведи).
5. Атмосфера фронтира: без ханжества и упадничества, церковь Ильматера гибкая, приветствует плодовитость и скрещивание народов; горожане безоговорочно верят проповедям отца Герхарда.
6. Стилистика:
   - Не более ОДНОГО описательного прилагательного на предмет или действие. Упор на глаголы, позы, жесты и взгляды.
   - Полный запрет на бытовые запахи окружения (таверны, кухни, пива, еды, пыли, пота, перегара).
   - Естественные запахи интима, возбуждения и семени в 18+ сценах разрешены и сохраняются.
   - Важные разговоры строй через живой обмен репликами (прямая речь `— «...»`), не пересказывай диалог в 2 предложениях.
   - Учитывай текущую стадию FamilyCorruptionStage (0–1: сдержанность и границы; 2–3: флирт и намёки; 4–5: открытая раскованность).
```

## 6. Вариант 4 — Интеграция прямо в Antigravity (Skill + локальный MCP-сервер)

В проект уже добавлена встроенная связка для Antigravity:

1. **Навык проекта:** `.agents/skills/openrouter-text-gen/SKILL.md` — учит агента в любой сессии вызывать `scripts/generate_text.py` с нужной моделью (`deepseek/deepseek-v4-pro` по умолчанию, `deepseek/deepseek-v3.1-terminus` как запасная для 18+) и форматом `*pl '...'`.
2. **Локальный MCP-плагин:** `.agents/plugins/openrouter-writer/` (`plugin.json` + `mcp_config.json`) и сервер `scripts/openrouter_mcp_server.py`. После перезапуска/новой сессии Antigravity получает встроенные MCP-инструменты:
   - `openrouter_generate_scene` — генерация сцены/диалога/18+ по канону проекта;
   - `openrouter_list_models` — просмотр пресетов моделей.

*(Опционально: чтобы подключать этот же локальный сервер глобально во всех проектах, добавьте блок из `.agents/plugins/openrouter-writer/mcp_config.json` в `C:\Users\<Ваш_Пользователь>\.gemini\config\mcp_config.json`.)*
