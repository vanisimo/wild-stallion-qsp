# Экономика и личные кошельки семьи

Документ фиксирует **утверждённый дизайн** долей, потолков прибыли и сюжетной мотивации через деньги.  
Связано: `docs/handoff.md` (аудит), `docs/policy-flow.md` (policy зала), `docs/design-character-intimacy-arc.md`, `docs/state.md`.

**Статус в коде:** шаги **1–3c** — доли, чаевые, траты, мечты (eavesdrop), sidebar, новое блюдо. **Собрание / гейт (§0, §0b) — дизайн утверждён, в коде нет.**

## 0. Порядок сюжета: клерк → мысль → ужин-собрание → гейт

**Не** после первого приёма у мэра (это далеко). Собрание — **ранний** акт-1 хаб.

### Цепочка

1. **Клерк** (после неудачной/платной попытки приёма): попытка ≠ приём; поднять доход «налогового объекта»; костюм; вывеска; ремонт/столяр; персонал; церковь/танцы; налог 10% растёт с доходом → порог «среднего объекта».
2. **Мысли ГГ:** можно **не только защищать** — мягче в зале ради кассы (задел «гейта разврата» / soft earn).
3. **Флаг дня:** «нужно поговорить с семьёй вечером» (`FamilyCouncilPending`).
4. **День** — обычная игра; флаг мыслей **не** снимать.
5. **Ночь** — автозапуск **семейного ужина** (`FamilyCouncil`). Опционально днём one-shot у мамы: *«закроем — за ужином»* (атмосфера, не единственный вход). Запасной act, если ночь сбили debug’ом.
6. **После собрания** — `FamilyCouncilDone = 1` + **один глобальный флаг** `FamilyLiberationGateOpen = 1` (см. ниже).

Мэр / печать / барон — **мотивация в рассказе за столом**, не триггер сцены.

### UX запуска

| | |
|--|--|
| **Главный** | переход в **ночь** → ужин |
| **Доп.** | реплика мамы днём; act «Собрание» если нужно |
| **Картинка** | семья за столом / ужин на все экраны |

### Экраны ужина — **6** (линейно, «Далее»)

| # | Содержание |
|---|------------|
| **1** | Бумага, Томас Лермонт → взгляд → кивок мамы → **Мелисса: до папы кто-то был, папа взял с ребёнком** → пауза (обе думают) → **Аманда: не наш братик??** → мама: единоутробный |
| **2** | Печать, мэр не принял, взятка; мама *«скотина, после всего…»* → *«после того что трактир делает для города»* (**foreshadow**, без признания) |
| **3** | Баронесса / бастард / перечёркнутый герб / «барончик» / «циц, сын дальше» |
| **4** | Клерк: попытка≠приём, объект, костюм; вывеска; столяр + мама *«кровать заодно»*; персонал; церковь/танцы; налог 10% |
| **5** | Фантазия ГГ («сисястее») vs **план мамы**: уборка + кухня-заготовки (невидимые в UI, только стат); мама готовит; сёстры+зал; ГГ стойка |
| **6** | Мягче в зале → возмущение → доли/чаевые → крема / стихи / ингредиенты → «улыбка и ручка, не на колени» → ГГ: *«на большее не рассчитывал… пока»* |

One-shot. Без ветвления концовок — спектакль + снятие морального груза.

### Персонал (канон к собранию)

| Когда | Кухня | Зал | Уборка |
|--------|--------|-----|--------|
| **До** найма по совету клерка | **мама** | **сёстры** | **1 женщина**, игрок **не видит** — только **цифры в статистике** |
| **После** (мама нанимает) | мама **готовит** + **помощница на заготовки** (только стат) | **без изменений** | **помощница уборке** (только стат) |

Сисястых «для зала» мама **режет**. Найм — через неё, не «жопами вертеть».

## 0b. Глобальный флаг после собрания

**Один** флаг на всю игру после ужина:

| Флаг | Значение |
|------|----------|
| `FamilyCouncilDone` | ужин сыгран |
| **`FamilyLiberationGateOpen`** | **глобальный** «гейт»: семья **знала и торговалась** за столом; рамка soft earn легитимна |

### Что флаг **делает** / **не делает**

| Не делает | Делает |
|-----------|--------|
| Не ставит всем policy 3, не качает sluttiness автоматом | Открывает / легитимирует **другие варианты** действий (улыбка, ручка, мягче правила — в формулировке собрания) |
| Не «все развратны» | Игрок **сам** крутит, куда дальше |
| Не снимает choice с ГГ | Снимает ощущение, что **только он** виноват, если крутит в грязь: семья слышала про доли и чаевые |

На старте после собрания **механика почти та же**; меняется **рамка** и доступность опций. Дальше — `FamilyCorruptionStage` / policy / sluttiness как сейчас.

Синонимы в текстах: `FamilySoftEarnAgreed` **не** плодить — только **`FamilyLiberationGateOpen`**.

## 1. Зачем это нужно

Раньше давление на девочек выглядело так: **ГГ приказал → они терпят → вся вина на хозяине**.

С личными долями появляется **вторая ось**:

- трактир кормит **их** кошельки (мелочи, быт);
- «потерпеть клиента» / смягчить правило = **чуть ближе к своим мелким радостям** (брошь, книга, специя), не только «угодить брату»;
- **предмет-мечта** (дорогое, редкое) — **отдельный** слой: обсуждают, **не** копят и **не** покупают сами; достаёт **ГГ** (заглушка квеста).

ГГ остаётся хозяином и автором правил, но тон «можно / нельзя / сама хочу» уже сидит в **существующих** шкалах (`FamilyCorruptionStage`, `sluttiness`, policy) — деньги и talk **подпитывают** их, а не плодят вторую лестницу.

## 2. Доли от прибыли (утверждено)

Доли считаются от **распределяемой** дневной прибыли (после расходов персонала, налога, supply-модификаторов).  
**Не** резать «бухгалтерскую» прибыль до закупки запасов так, чтобы ГГ остался без COGS: либо доли от **свободного остатка**, либо закупка из общей кассы трактира, а доли — после.

| Член | % | Части (/40) | Роль |
|------|---|-------------|------|
| **Стефан** | **70%** | 28 | основная доля хозяина |
| **Сандра** | **15%** | 6 | меньше ГГ |
| **Аманда** | **7.5%** | 3 | ½ доли матери |
| **Мелисса** | **7.5%** | 3 | ½ доли матери |

Правило: каждая девочка = **половина доли матери**; две девочки вместе = доля матери; ГГ = остальное (**70%**).

### Переменные (план)

| Кто | Переменная | Примечание |
|-----|------------|------------|
| Стефан | `money` | как сейчас |
| Сандра | `SandraMoney` | или `FamilyWallet['sandra']` |
| Аманда | `AmandaMoney` | |
| Мелисса | `MelissaMoney` | |

`AddGirlWorkExpenses` (12/22/42) — **абстрактный cost** в формуле, **не** перевод на кошельки.  
Налог (`TaxPercent`, `TavernCityTaxTotal`) — с **gross**, не с доли ГГ; честная ветка мэра по дням казны **не** удлиняется из‑за долей.

### Точка вшивания

`ProcessTavernWorkDay` / после финального `tavern_expected_profit` (после tax + events + supply):

```
// псевдокод
share_base = tavern_expected_profit   // или free-cash после COGS-учёта
if share_base > 0:
  money += share_base * 28 / 40
  SandraMoney += share_base * 6 / 40
  AmandaMoney += share_base * 3 / 40
  MelissaMoney += share_base * 3 / 40
else:
  money += share_base   // убыток — на хозяина (утвердить при коде)
```

В сводке дня показывать **разбивку долей**, не только «Прибыль / Деньги ГГ».

## 3. Потолок прибыли (оценка по формулам)

Источники: `tavern_income.qsps`, `next_day` (гости), `tavern_upgrades`, `tavern_reputation`.

### Рычаги

| Рычаг | Эффект | Потолок |
|-------|--------|---------|
| `tavernvisitors` | линейно | обычно **≤80**, ивенты до **85** |
| `tavern_reputation` | `rep_mult` | **×1.6** при ≥90 |
| kitchen/waitress power | `staff_mult = 50+power` | **×1.4** (power **90** достаточно) |
| апгрейды | +5% напитки; пт +10% пиво; +гости | малые |
| цены | 15 / 20 / 10 | **фиксированы** |
| налог | −10% gross | растёт с доходом |
| ивенты | ± к profit | плюс до ~**+85** |

**Важно:** power **>90** доход не поднимает, но **увеличивает расход запасов** → free cash падает. Оптимум ~**90/90**.

### Оценки «свободных» (после COGS-оценки закупа)

| Сценарий | Gross | Учётная прибыль | Free ≈ | ГГ 70% | Мать 15% | Дочь 7.5% |
|----------|------:|----------------:|-------:|-------:|---------:|----------:|
| Ранний (v~25, старт skills) | ~340 | ~270 | **80–90** | ~60 | ~13 | ~7 |
| Середина (v~50, апгрейды, rep 90+) | ~1.3–1.5k | ~1.1–1.3k | **550–600** | ~400 | ~90 | ~45 |
| Мягкий макс (v60–64, power 90) | ~2.0–2.2k | ~1.8–1.9k | **700–760** | ~500 | ~110 | ~55 |
| Жёсткий потолок (v80, mult max) | **~2725** | **~2417** | **~955** | **~670** | **~140** | **~70** |
| + пятница / жирный ивент | ~2.8k+ | ~2.5k | **~1.0–1.1k** | ~700–770 | ~150–165 | ~75–80 |

Отдельно: работа за стойкой **+15–40** → только `money` ГГ (не делится).

Рост прибыльности трактира **прямо** увеличивает скорость копилок всех четверых.

## 4. Три слоя: кошелёк / предмет-мечта / жизненный talk

Не смешивать.

| Слой | Что | Кто добывает | Деньги девушки |
|------|-----|--------------|----------------|
| **Кошелёк** (`*Money`) | мелочи: брошь, духи, том «просто почитать», специя на ужин | **сама** (тратит с доли/чаевых) | да |
| **Предмет-мечта** | одно редкое «хочу» на девушку | **только ГГ** (talk → заглушка квеста → найти/достать) | **нет** — не копит, не покупает, не ищет |
| **Жизненный talk** | приданое, «издать стихи», «первый повар побережья» | сюжет/тон | **не** = цена мечты-предмета в лавке |

Предметы-мечты **не убирали** из дизайна — срезало упрощение gifts до `gift_cheap`/`gift_expensive`. **Вернуть слой:** talk + флаги + stub квеста (не обязательно старые 22 полки).

## 4a. Предметы-мечты (канон, квест ГГ)

### Правила

- В **ротации магазина нет** (или «такого не продают»).
- **Не** разговор с ГГ в GirlTalk («Поболтать…») — у нас **не** было и **не** делаем прямую тему «про мечту» к Стефану.
- Узнаёт ГГ: **подслушивание** воскресенье **день/вечер** (`sunday_visits`) — разговоры **NPC↔NPC**:
  - **Аманда+Лизетта** (комната, `AmandaLizaTalk`) — ростовое стеклянное зеркало;
  - **Сандра+Бекки** — «Рецепты Короны», зеркало Аманды, **постоянный** «конский» смех про огурцы (салат до/после и т.п.);
  - **Мелисса+Кларисса** — Элеонора т.3, зеркало Аманды, **золотое вино** Клариссы (заткнуть мужа с его розовым к королевскому столу);
  - **Инга+Ирма** — машинка Инги; **посох предков** Ирмы (службы у Древа).
- **Не** списывать мечту с `*Money` девушки; сама **не** ищет и **не** копит на предмет.
- Тон talk у **всех** мечт: **хотелось бы, увы** — приценивалась / то дорого, то не продают, то уехало. **Не** «принеси мне» / «кто найдёт — герой».
- После подслушивания: `DreamItemKnown[id]`, `PlayerKnows_Dream_*` — знание для будущего квеста (без пина в тексте).
- `DreamItemGiven[id] = 1` — фраза выпадает из пула (после вручения, stub).

### Семья

| Кто | id (план) | Предмет-мечта | Смысл / talk |
|-----|-----------|---------------|--------------|
| **Аманда** | `full_length_mirror` | **Ростовое зеркало из стекла** — дорогое, богатое, рама резная/золочёная; **не** «как у всех» полированное серебро, в котором лица не разобрать | «С таким в приданом — хоть за дворянина»; видно себя **ясно**, с ног до головы; **не** карманное зеркальце (`hand_mirror`) |

| | |

## 5. Два потока денег + чаевые

| Поток | Куда | От чего |
|-------|------|---------|
| **Доля дня** | кошелёк члена семьи | % от прибыли трактира (§2) |
| **Чаевые** | **личный** кошелёк девушки (не в общий `money` ГГ) | раскрепощённость + policy + сцена |

### Чаевые (уже есть зачатки в коде)

Сейчас: `TavernHallEventTips` и микро-ивенты зала кладут чаевые в **`money`** ГГ (`tavern_hall_events.qsps`, `tavern_events.qsps`).  
**Целевое:** чаевые → `AmandaMoney` / `MelissaMoney` / `SandraMoney` (кто обслужил).

Зависимость от **раскрепощённости** (не новая шкала — использовать уже существующие):

| Фактор | Переменная / правило | Эффект на чаевые |
|--------|----------------------|------------------|
| Личная раскрепощённость | `sluttiness[girl]` | основной множитель (низкий → копейки, высокий → щедрее) |
| Правило работы | `GirlWorkPolicy` / `GirlKitchenPolicy`: **0** нет / **1** приличная / **2** сама / **3** удержать ради чаевых | 1 = скромно; 2–3 = выше потолок |
| Семья | `FamilyCorruptionStage` | мягкий множитель фона (на stage 0 гости «не ждут», на 4–5 — ждут большего) |
| Сцена | hall tips / attention / lewd_good | разовый roll, как сейчас |

Черновая формула (баланс playtest):

```
base = 2..8
tips = base + sluttiness/10 + policy_bonus(0/0/3/6)
tips = tips * (100 + FamilyCorruptionStage*5) / 100
// clamp 0..40 за микро-ивент; щедрый ивент 10..30 как сейчас, но на её кошелёк
```

Смысл: **чем вольнее держится — тем жирнее копилка цели** (приданое / книга / старость+кухня).  
ГГ по-прежнему задаёт policy и забирает 70% оборота; девочка **чувствует** выгоду терпения на своей шкуре.

Связь: `docs/policy-flow.md`, `GirlWorkPolicy` в `docs/state.md`.

## 6. Лестница — только существующий код (не плодить)

**Не вводить** отдельные `reject/consider/agree/accept/break` и не плодить «моральную стадию 2.0».

Уже есть и этим пользоваться:

| Система | Где | Диапазон | Роль |
|---------|-----|----------|------|
| **`FamilyCorruptionStage`** | `HallFamilyStateUpdateStage` | **0…5** | семейный уклад: от приличных границ до сломанных |
| **`FamilyCorruptionPoints`** | + через `HallFamilyStateApply` | 0…100 | накопление → stage |
| **`FamilyTrust` / `FamilyTension`** | там же | 0…100 | доверие / давление |
| **`sluttiness[girl]`** | NPC init + сцены | растёт | личная раскрепощённость → чаевые, тон, гейты |

| **Intim-лестницы** | sex/home | отдельно | **не** путать с залом |

Пороги stage (код): points ≥8→1, ≥20→2, ≥35→3, ≥55→4, ≥80→5.

### Смысловая проекция (тексты/тон), не новые enum

Нарратив «неприятие → можно → согласие → приятие → за запрет» = **как писать**, опираясь на **уже посчитанный** stage + sluttiness + policy:

| `FamilyCorruptionStage` | Тон семьи / зала | Деньги | «Кто виноват» в текстах |
|-------------------------|------------------|--------|-------------------------|
| **0** | Неприятие: «это не мы» | Доля есть, чаевые мизер; цель почти не оправдывает грязь | В основном **ГГ** (правила) |
| **1** | «Так, кажется, можно…» — внутренний торг | Считает дни до покупки/маяка | ГГ + «нужда» |
| **2** | Согласие в рамках приказа (policy 1–2) | Чаевые заметны; траты на цель | Делит: правило + карман |
| **3** | Приятие: меньше упрёков, policy 2 привычен | Цель двигается; Аманда — красота, Мелисса — книга | «Так зарабатываем» |
| **4** | Запреты плывут; policy 3 / missing / lewd | Чаевые жирные; sluttiness кормит копилку | Доля вины **с ГГ** на «сама / привыкли» |
| **5** | Границы сломаны (AGENTS: stage 5) | Макс. личный интерес + риск скандала | Инициатива девочек / семьи, не только приказ |

**Лично** (параллельно stage): высокий `sluttiness` + policy 3 → больше чаевых и «сама тянется»; низкий sluttiness при dirty-выборе ГГ → злость, tension, обвинение брата.

Движок stage **уже** крутит `HallFamilyStateApply` (protect/warn vs profit/encourage/ignore). Экономика **не** дублирует это — только:

- кладёт деньги на кошельки;
- даёт **текстам** крючок «ещё X до приданого/книги/зимы»;
- усиливает **желание** терпеть (чаевые × sluttiness).

Intim-stage (дом/секс) остаётся **своей** лестницей — см. `design-character-intimacy-arc.md`.
